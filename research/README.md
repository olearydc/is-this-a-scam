## What we learned

- **Nobody else does what we do for Ireland.** No Irish paste-and-check tool exists. FraudSMART's `scamchecker.ie` checks website addresses only, so it's a good link to add, not a rival.
- **Our privacy is a real advantage.** Most rivals upload messages, need an account, or charge for the good parts. Ours runs in the browser with no sign-up.
- **Never saying "safe" is unusual and right.** Several rivals say "safe" or offer "mark as safe".
- **Nobody helps with "someone is on the phone to me right now".** That's a gap we can fill.
- **Training fades in about two weeks**, so short refreshers beat one long quiz. Explaining each answer works better than right/wrong alone. Older people blame themselves, so wrong answers must never shame.
- **There is no verified Irish number for forwarding scam texts.** 50050 is NOT verified. Vodafone's old page says 50005 and is undated. Don't publish either until the operators confirm.
